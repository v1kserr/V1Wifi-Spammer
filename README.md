## 🧭 Что это?

**V1Wifi-Spammer** — это скрипт, который создаёт множество фейковых точек доступа (SSID) с помощью `aircrack-ng` и `airbase-ng`. Используется для тестирования поведения клиентов в окружении множества сетей, проверки устойчивости устройств, а также в учебных целях.

## 🛰 Подготовка Wi-Fi адаптера

### Шаг 1. Узнаём имя интерфейса

```bash
iwconfig
```

В выводе вы увидите что-то вроде:

```
wlan0     IEEE 802.11  ESSID:off/any
          Mode:Managed  ...
wlan1     IEEE 802.11  ESSID:off/any
          Mode:Managed  ...
```

`wlan1` — это имя вашего Wi-Fi адаптера. **У вас оно может отличаться!**

### Шаг 2. Включаем режим мониторинга

```bash
sudo airmon-ng start wlan1
```

> 💡 **Совет:** если `airmon-ng` ругается на занятые процессы, выполните:
> ```bash
> sudo airmon-ng check kill
> ```

### Шаг 3. Проверяем новое имя интерфейса

```bash
iwconfig
```

После включения монитора имя может измениться:

- было `wlan1` → стало `wlan1mon`
- иногда остаётся прежним

**Запомните это имя** — оно понадобится при запуске.

## 🚀 Запуск

```bash
sudo python3 V1Wifi_Spammer.py
```

Скрипт пошагово спросит:

1. **Количество фейковых сетей** — сколько SSID создать
2. **Название фейковых сетей** — базовое имя (например, `FreeWiFi`)
3. **Имя Wi-Fi адаптера** — то, что вы узнали на шаге 3 (`wlan1` или `wlan1mon`)

После ввода всех параметров скрипт запустит создание сетей.

Для остановки нажмите `Ctrl + C`.

## 🛠 Возможные проблемы (FAQ)

**🔹 `airmon-ng: command not found`**
Не установлен `aircrack-ng`. Установите: `sudo apt install aircrack-ng`

**🔹 Адаптер не поддерживает режим мониторинга**
Проверьте модель адаптера. Подходят чипы: Atheros AR9271, Ralink RT3070, Realtek RTL8812AU и подобные. Встроенные адаптеры ноутбуков часто **не подходят**.

**🔹 `monitor mode vif enabled for ... on ...` — но сетей не видно**
Убедитесь, что скрипт запущен с `sudo` и адаптер действительно в режиме `Monitor`.

**🔹 Ошибка `Device or resource busy`**
Выполните:
```bash
sudo airmon-ng check kill
```
и повторите запуск.

**🔹 После перезагрузки адаптер не в режиме мониторинга**
Режим мониторинга сбрасывается при перезагрузке. Повторяйте шаги из раздела «Подготовка».
